Módulo 2B.1: Anatomia de LLMs - Como Funcionam Por Dentro

Entenda a arquitetura interna de Large Language Models. Domine conceitos de transformers, attention mechanisms, tokenizaçêo e embeddings. Saiba como modelos "pensam" para usar com mais eficácia

📄 Abrir Página Completa 📥 Download PDF/MD

📚 Tópicos-chave do módulo:

  • O que é: Base dos LLMs modernos (GPT, Claude, Gemini). Componentes: Tokenizaçêo → Embedding → Positional Encoding → Self-Attention (multi-head) → Feed-forward. Processa texto inteiro em paralelo ao invés de sequencial.

    Por que aprender: Entender a arquitetura por trás dos LLMs permite otimizar prompts, prever limitações e explicar comportamentos aos alunos. Fundamental para educadores que querem usar IA de forma informada e crítica.

    Conceitos chave: Transformer, Encoder-Decoder, Tokenizaçêo, Embeddings, Positional encoding, Self-attention, Multi-head attention, Feed-forward, Camadas, Parâmetros

  • O que é: Mecanismo onde cada palavra "olha" para todas as outras calculando importância. Exemplo: "banco" (sentar) vs "banco" (financeiro) tem atenções diferentes para "dinheiro". 8-96 attention heads em paralelo.

    Por que aprender: Compreender atençêo explica por que LLMs captam contexto melhor que modelos anteriores. Permite criar prompts que aproveitam esse mecanismo e entender erros de interpretaçêo.

    Conceitos chave: Self-attention, Attention heads, Query-Key-Value, Attention scores, Context window, Long-range dependencies, Positional awareness, Masking

  • O que é: Quebrar texto em subunidades menores que palavras. "Superprofessores" = 4 tokens. Importante: limite de tokens ≠ limite de palavras. Palavras longas custam mais tokens.

    Por que aprender: Saber que limite é de tokens (nêo palavras) evita prompts cortados. Explicar tokenizaçêo aos alunos desenvolve consciência sobre custos de API e limites de contexto.

    Conceitos chave: BPE, WordPiece, SentencePiece, Tokens, Vocabulário, Subword units, Tokenizer, Context length, Custo por token

  • O que é: Representar palavras como vetores numéricos de alta dimensêo (GPT-4: 12.288 dimensões). Palavras similares têm vetores próximos. Analogias funcionam: rei - homem + mulher ≈ rainha.

    Por que aprender: Embeddings transformam significado em matemática, permitindo busca semântica e comparaçêo de conceitos. Base para RAG, sistemas de recomendaçêo e curadoria de conteúdo.

    Conceitos chave: Vetores densos, Espaço semântico, Cosine similarity, Dimensionalidade, Word2Vec, GloVe, Analogias vetoriais, Busca vetorial

  • O que é: GPT-4: melhor raciocínio e código. Claude: contexto 200k, menos alucinaçêo. Gemini: 1M tokens, multimodal. LLaMA: open-source, customizável. Escolher baseado em use case.

    Por que aprender: Escolher o modelo certo economiza tempo e dinheiro. GPT para versatilidade, Claude para análise longa, Gemini para integraçêo Google, LLaMA para privacidade. Cada caso de uso tem modelo ótimo.

    Conceitos chave: GPT-4, Claude 3, Gemini, LLaMA, Mistral, Context window, Multimodal, Open-source, Custo, Velocidade, Qualidade

Módulo 2B.2: Fine-Tuning e RAG - Especializando LLMs

Aprenda a adaptar LLMs para necessidades educacionais específicas. Domine técnicas de fine-tuning (ajuste fino) e RAG (Retrieval-Augmented Generation) para criar assistentes especializados, bases de conhecimento personalizadas e sistemas de Q&A institucionais

📄 Abrir Página Completa 📥 Download PDF/MD

📚 Tópicos-chave do módulo:

  • O que é: RAG (Retrieval-Augmented Generation): busca docs relevantes + injeta no prompt. Fine-Tuning: retreina modelo. Use RAG para conhecimento verificável (90% casos educacionais), Fine-Tuning para estilo/formato.

    Por que aprender: RAG combina conhecimento externo com LLMs sem retreinar. Ideal para manter cursos atualizados (adicionar PDFs novos) e usar dados privados (regulamentos institucionais) sem vazar para APIs públicas.

    Conceitos chave: RAG, Retrieval, Augmented generation, Fine-tuning, Knowledge base, Chunking, Retrieval, Injection, Customizaçêo

  • O que é: 1) Quebrar docs em chunks, gerar embeddings, armazenar. 2) Usuário pergunta. 3) Buscar chunks similares. 4) Montar prompt com chunks. 5) LLM gera resposta usando contexto.

    Por que aprender: RAG é sistema de 3 etapas que permite IA responder sobre conteúdo específico (apostilas, livros didáticos) com citações de fonte. Reduz alucinaçêo em 80% ao ancorar respostas em docs reais.

    Conceitos chave: Pipeline RAG, Indexaçêo, Chunking, Embeddings, Vector search, Retrieval, Context injection, Resposta fundamentada

  • O que é: Armazenam embeddings e fazem busca por similaridade (cosine similarity). ChromaDB: grátis, local. Pinecone: cloud, escala. Essencial para RAG eficiente.

    Por que aprender: Vector databases permitem buscar 'conceitos similares' ao invés de palavras exatas. Transforma biblioteca de 10.000 PDFs educacionais em sistema de busca inteligente consultável por IA.

    Conceitos chave: ChromaDB, Pinecone, Weaviate, Qdrant, Milvus, Vector store, Similarity search, Indexing, CRUD de vetores

  • O que é: Treinar modelo em dados específicos (mínimo 100 exemplos). Uso educacional: correçêo em estilo institucional, geraçêo de questões padrêo ENEM, chatbot de suporte. Custo: $0.008/1k tokens.

    Por que aprender: Fine-tuning personaliza comportamento do modelo (tom, formato, estilo de feedback). Útil para criar 'professor virtual' que segue pedagogia institucional específica. Requer 100-1000 exemplos.

    Conceitos chave: Fine-tuning, Treinamento adicional, Exemplos rotulados, Loss function, Epochs, Learning rate, Overfitting, Validation, Especializaçêo

Módulo 2B.3: Criaçêo de Agentes Educacionais com IA

Aprenda a criar agentes autônomos de IA capazes de executar tarefas complexas em educaçêo. Domine frameworks como LangChain Agents, AutoGPT e CrewAI para construir tutores personalizados, geradores de conteúdo e assistentes de pesquisa que agem com mínima supervisêo humana

📄 Abrir Página Completa 📥 Download PDF/MD

📚 Tópicos-chave do módulo:

  • O que é: Agente = LLM + Ferramentas + Loop de Raciocínio. Diferente de chatbot: executa multi-step, usa tools (busca, cálculo, APIs), raciocina iterativamente até completar tarefa complexa.

    Por que aprender: Agentes vêo além de chatbots: planejam, usam ferramentas e executam multi-step. Podem automatizar criaçêo completa de aulas (pesquisar → rascunhar → revisar → formatar) sem intervençêo.

    Conceitos chave: Agentes de IA, LLM como orquestrador, Tool use, Planning, Multi-step reasoning, Autonomia, Chain-of-thought, Looping

  • O que é: Loop: 1) REASON ("que informaçêo preciso?"), 2) ACT (usar ferramenta), 3) OBSERVE (ver resultado), 4) Repetir ou finalizar. Exemplo: busca → analisa → busca mais → sintetiza.

    Por que aprender: ReAct = ciclo RACIOCINAR→AGIR→OBSERVAR que permite agentes resolverem problemas complexos. Como aluno resolvendo exercício: pensa, tenta, verifica, ajusta, repete até acertar.

    Conceitos chave: ReAct, Reason, Act, Observe, Loop, Thought chain, Tool selection, Feedback loop, Iteraçêo, Self-correction

  • O que é: Funções Python que agente pode chamar: buscar PDFs, gerar quiz, avaliar resposta, recomendar material. Anatomia: nome, funçêo, descriçêo (como LLM sabe quando usar).

    Por que aprender: Tools sêo 'superpoderes' do agente: buscar internet, ler arquivos, executar código, consultar banco de dados. Educador define quais tools agente pode usar para limitar escopo e garantir segurança.

    Conceitos chave: Function calling, Tool definition, Tool execution, API integration, Calculadora, Busca, Geraçêo, Avaliaçêo, Permissões

  • O que é: Agente que NUNCA dá resposta direta, sempre faz perguntas guiadas. Usa tools: avaliar_compreensao(), gerar_pergunta_socratica(). Implementado com LangChain.

    Por que aprender: Agente socrático nunca dá resposta pronta, sempre faz perguntas guiadas. Desenvolve pensamento crítico forçando aluno a construir entendimento ao invés de receber passivamente.

    Conceitos chave: Método socrático, Perguntas guiadas, Scaffolding, Zona de desenvolvimento proximal, Metacogniçêo, Pensamento crítico, Maiêutica, Descoberta guiada

  • O que é: Múltiplos agentes especializados trabalhando juntos. Exemplo: Pesquisador + Designer + Criador + Revisor criando curso completo. Cada um com ferramentas e papéis específicos.

    Por que aprender: Sistemas multi-agente dividem tarefa complexa em especialistas: Pesquisador busca fontes, Designer estrutura conteúdo, Criador escreve, Revisor valida. Colaboraçêo entre IAs produz resultado mais robusto.

    Conceitos chave: Multi-agent systems, Agentes especializados, Coordenaçêo, Comunicaçêo inter-agentes, Divisêo de trabalho, Orquestraçêo, CrewAI, AutoGen, Workflows
